Use with AI

One file, any AI tool, on-brand slides

01
Give it DESIGN.md

Attach or paste the spec: rules, tokens, type scale and all 27 components.

02
Describe your talk

Title, sections, demos. Pick the TopicTag or Headline style.

03
Get an HTML deck

1920×1080 slides that link the tokens and slide CSS from this repo.

04
Present or export

Arrow keys to present, or ask for PowerPoint, Google Slides or Keynote using the same spec.

// example promptUsing the attached DESIGN.md, create a 20-slide HTML deck for my talk "Building Offline-First Apps with Kotlin Multiplatform". Use the TopicTag header style, one StatementSlide per section, two demos, KeyTakeaways and the ClosingSlide. Output one HTML file that links tokens/tokens.css and css/slides.css.
